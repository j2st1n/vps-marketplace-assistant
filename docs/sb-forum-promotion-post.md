# 受不了二手市场手动按计算器和被墙机霸屏，顺手搓了个交易所油猴脚本（支持 Panstar / Akile / Isvoro）

前天晚上在 Akile 的 Push 市场看机器，刷到一台标价 28 块的小鸡，配置写着年付 140，还有四个月多几天到期。我切出浏览器，点开手机计算器算了一下，还剩 132 天，每天折合三毛八，剩余价值差不多五十块钱。卖家卖 28 块，等于白白倒贴二十多块，按理说是笔划算买卖。我没多想就点了付款。机器到手一连，ssh 怎么都连不上，丢去测试平台一测，海外全通，国内一片红。手头平白多了一台不能用的机器，找官方换 IP 还要交二十块工单费，折腾一圈倒贴进去将近五十块。

经常在二手市场收鸡出鸡的人，大概都遇到过这种事。

除了这种挂低价甩被墙机的坑，平时逛市场还有两件事让人头疼。

一个是算账太累。市场里的卡片只给一个续费总额和到期时间。看到一台机器，得先算今天离到期日还差多少天，再把年付或者季付除出每天的单价，最后乘出剩余价值，才能对比卖家到底是倒贴了还是加价了。有时候刚在计算器上按完，切回浏览器想买，卡片已经灰了，被人抢先秒走。

另一个是价格周期混在一起容易看走眼。有的机器年付三十六块，折合一个月三块钱，卖家挂三十出，第一眼看着不算便宜，但接手之后一年才几十块续费，属于典型的传家宝。旁边一台月付三十的机器挂十五出，看着只要十五块，买回去每个月续费都得三十。两台机器摆在一起按售价排，月付那台排在前面，不仔细换算很容易买错。

我以前试过别人写的单平台脚本。有的只能在 Akile 用，换到 Panstar 或者 Isvoro 又得另外找插件。有的遇到单页路由跳转会直接失效，从控制台点进市场必须按 F5 刷新才出来；要是遇上骨架屏加载慢，甚至卡死在半路上。

前几天索性自己动手写了一个，把 Panstar、Akile 和 Isvoro 三个市场的逻辑合在一起，取名叫《VPS 交易所助手》。昨天测完最后一轮，顺手传到了 GreasyFork 上，源码也放在了 GitHub。

脚本主要做了几件实在事。

第一件是把账直接算在卡片上。安装之后打开市场，每台机器底下会自动多出一行数据。里面标了精准到分的剩余价值、接手之后每天折合几毛钱，还有卖家让利了多少。遇到卖家亏本甩卖，卡片会直接打上绿色的倒贴标签和实际折扣；遇到加价转让，换成黄色或者红色的溢价标签。想捡漏的时候一眼就能看清谁在放血让利。

第二件是把被墙机器赶出前排。我在所有排序算法底层给被墙和阻断的机器加了一亿权重的惩罚分。不管是按倒贴排序还是按低价排序，只要 IP 异常，机器就会排到最后一页垫底，不会再顶着几块钱的标价挡在前面晃眼。控制面板里也加了一个一键隐藏被墙机的开关，点一下整个列表就清爽了。

第三件是把续费周期拉平。控制面板里除了倒贴排序和低价排序，专门做了一个月均续费最低排序。系统会自动把年付、半年付、季付和月付全部折算成每个月的续费成本。三十块一年的机器折合每月两块五，一百二十块一年的机器折合每月十块。点一下这个排序，那些续费极低、适合长期留着当备用的绝版小鸡会直接浮到最前面。

第四件是做了几个前端细节处理。脚本接入了路由监听，从用户中心点进市场，或者在不同分类之间来回切，都不用手动刷新页面。针对加载慢的情况做了数据指纹比对，页面骨架屏还在的时候先不动作，等真实数据卡片上屏之后再注入计算结果，不会再因为异步加载而失效。Isvoro 的卡片排版结构比较特殊，我也专门做了布局隔离，保证两列网格不会塌陷错位。晚上习惯关灯看屏幕的话，它会自动跟随系统的暗色模式，卡片颜色不会刺眼。

安全性方面大家可以放心。平时论坛里老哥们对油猴脚本都很谨慎，最怕偷 Token 或者后台上报数据。这个脚本在元数据里声明了无需特殊权限，也就是 @grant none，没有任何外部网络请求，更没有引入第三方统计。所有的价格、时间解析和数学运算全在浏览器本地完成，不碰任何账号信息和 Cookie。源码在 GitHub 和 GreasyFork 都是完全公开的，懂前端的老哥随时可以按 F12 审查。

脚本支持 Tampermonkey、Violentmonkey 和 ScriptCat。平常在 Panstar、Akile 或者 Isvoro 蹲机器的朋友可以装上试试。我自己前前后后跑了九十多项测试用例，大毛病基本清掉了。如果大家在使用时遇到哪台机器的周期没认出来、哪个页面排版对不上，或者想要什么顺手的小功能，直接在帖子里跟帖说一声，我抽空更新。
